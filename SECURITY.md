# Security Policy

## Supported Versions

Only the latest version of HelmKeeper is currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an e-mail to the maintainer (marcoadasilvaa@gmail.com) or open a **Private** Vulnerability Report on GitHub.

**Do NOT create a public issue for security vulnerabilities.**

We will address the issue as soon as possible.
